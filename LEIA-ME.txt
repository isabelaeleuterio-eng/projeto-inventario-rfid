INVENTARIO RFID - VERSAO FINAL

PASTA OFICIAL:
PROJETO-INVENTARIO-RFID-LIMPO

FLUXO:
1. Passe a tag do funcionario.
2. Se nao houver emprestimo ativo, escolha retirar ou devolver.
3. Escolha UM equipamento.
4. Passe novamente a tag fisica do equipamento.
5. Somente a tag correta conclui a operacao.
6. Se o funcionario ja tiver um equipamento, o sistema bloqueia outro ate a devolucao.

REGRA DA BOX:
Cada box comporta apenas um objeto. O cadastro e a edicao recusam box duplicada.
Ao iniciar, o servidor tambem corrige automaticamente box_id duplicado existente, atribuindo a proxima box livre.

ESP32:
POST /api/esp32/rfid com JSON {"uid":"...","leitor":"entrada"}.
O servidor aceita UID com espacos e tambem campos UID, uid_tag, tag e rfid.

DEPLOY:
npm install
npm start

git add .
git commit -m "Versao final RFID"
git push origin master

O Render publica automaticamente.
Nao altere o .env que ja funciona.
